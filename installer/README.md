# 🌰 NutNotes Installer & Updater

Автономный установщик и система автообновления для расширения **NutNotes** в Cockos REAPER.

---

## 📦 Что делает собранный установщик (`NutNotes_Setup.exe`)

1. **Проверка запущенного REAPER**:
   - Автоматически проверяет, открыт ли `reaper.exe` (через класс окна `REAPERwnd`). Если открыт — просит пользователя закрыть программу во избежание блокировки DLL и конфигов.
2. **Умное определение пути REAPER**:
   - По умолчанию ставит в стандартный каталог: `%APPDATA%\REAPER` (`C:\Users\<User>\AppData\Roaming\REAPER`).
   - Поддерживает **Portable-версии REAPER**: Установщик попробует найти расположение сам, но, в случае чего, можно указать любую папку с портативным REAPER, установщик распознает её и развернет все компоненты туда.
3. **Двухрежимная установка (Автономная + GitHub Updater)**:
   - При наличии интернета установщик делает быстрый запрос к GitHub API (`https://api.github.com/repos/BelkaVBanke/NutNotes/releases/latest`).
   - Если версия на GitHub новее вшитой: предлагает скачать и поставить самое свежее обновление в один клик.
   - Если версии совпадают, нет интернета или превышен лимит GitHub: **без лишнего скачивания и задержек устанавливает проверенную вшитую версию**.
4. **Автономные 64-битные зависимости в `UserPlugins/`**:
   - В установщик уже вшиты эталонные x64 бинарники:
     - `reaper_imgui-x64.dll` (движок графического интерфейса ReaImGui)
     - `reaper_reapack-x64.dll` (менеджер пакетов ReaPack)
   - Пользователю не нужно ничего искать, ставить вручную или компилировать.
5. **Файлы плагина в `Scripts/NutNotes/`**:
   - `NutNotes.lua` (главный скрипт)
   - `modules/*.lua` (модули логики, интерфейса, парсинга, оверлея)
   - `assets/*` (иконки и графика)
   - `test_samples/*` (демонстрационные субтитры и проекты)
6. **Регистрация экшена в `reaper-kb.ini`**:
   - Автоматически создает запись действия в Main Action Section:
     `SCR 4 0 _RS_NUTNOTES_LAUNCHER "Script: NutNotes.lua" "NutNotes/NutNotes.lua"`
   - Плагин сразу доступен в списке Actions (по клавише `?`) и готов к запуску.
7. **Опции при установке**:
   - 🔲 **Автозапуск NutNotes при старте REAPER**: прописывает безопасный блок в `Scripts/__startup.lua`.
   - 🔲 **Кнопка на панель инструментов (Main Toolbar)**: добавляет 3-позиционную иконку в `reaper-menu.ini`.
8. **Чистое удаление (`unins000.exe`)**:
   - Удаляет папку `Scripts/NutNotes`.
   - Удаляет запись из `reaper-kb.ini`.
   - Удаляет кнопку из тулбара в `reaper-menu.ini`.
   - Очищает хук из `Scripts/__startup.lua`.
   - Не трогает пользовательские проекты и настройки самого REAPER.
